## Git Skills Learned.
Commands that I have already known and its defenitions:
- git branch name - creates a new alternative branch 
- git switch - switches between branches
- git status - shows git state including change files
- git log - shows logs
- git push - pushes commits into remote repository
- git commit - creates a commit from staging area elements
- git add - adds elements into staging area for the future saving
etc.
